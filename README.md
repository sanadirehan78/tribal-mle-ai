# Tribal MLE AI

## Offline AI Teaching Assistant for Tribal Mother-Tongue Education

An AI-powered teaching assistant designed to help Hindi-medium primary school
teachers deliver Foundational Literacy and Numeracy (FLN) education in Santali.

## Prototype

Hindi → Santali

## Main Features

- Hindi → Santali text translation
- Hindi voice → Santali voice
- Bilingual FLN lessons
- Automatic bilingual worksheets
- Educational flashcards
- Offline-first operation

## Technology

- Python
- AI / NLP
- IndicTrans2
- IndicConformer
