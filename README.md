# Tribal MLE AI

Offline AI Teaching Assistant for Tribal Mother-Tongue-Based Education.

## Prototype

Hindi → Santali

## Main Features

- Hindi → Santali translation
- Hindi voice → Santali voice
- Bilingual FLN lessons
- Bilingual worksheets
- Educational flashcards
- Offline-first operation
